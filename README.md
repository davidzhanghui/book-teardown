# Book Teardown · 拆书

一个「拆书」仓库：每本书一个目录、一个解读系列，每篇只回答一个核心问题——非虚构拆解观点与知识地图，文学作品细读人物、主题与写法，并明确区分**事实、作者观点与不同解释**。

## 在线阅读

直接打开根目录的 [`index.html`](./index.html) 即可浏览全部书籍卡片；每个系列内还有自己的 `index.html` 目录页，点击卡片逐篇阅读。

```
open index.html        # macOS 直接打开总目录
# 或起一个静态服务
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

所有 HTML 均为自包含静态页面（明暗主题、侧边 TOC、Mermaid 图），无需构建。


## 系列写作规范

- `00｜系列拆解与目录`：全书简介、核心问题分层表、知识地图（Mermaid）、全系列目录与推荐星级、阅读顺序。
- 每篇解读只回答**一个核心问题**（文件名即问题），正文区分观点 / 事实 / 争议。
- Markdown 原稿与 HTML 成品同名并存，改稿后重新生成 HTML 即可。
